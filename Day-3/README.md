# Day 3 – Cafe Napoli AI Customer Service Assistant
-------------------------------------------------------
# Project Description
An AI-powered customer service chatbot built using Python, LangChain, and Groq. The assistant helps customers by answering questions about Cafe Napoli's menu, prices, best-selling items, and chef's specials.

# Technologies Used
- Python
- Google Colab
- LangChain
- Groq API
- CSV

# Features
- Answers customer questions about the cafe.
- Provides menu items and prices.
- Recommends best-selling items and chef's specials.
- Maintains conversation history.
- Handles unavailable menu items politely.
- Uses automated tests to evaluate responses.
- Demonstrates how temperature affects AI responses.

# Project Files
- `Day_3_Cafe_Napoli_AI_Assistant.ipynb` – Main project notebook.
- `tests.csv` – Contains 10 test questions and expected keywords.

# How to Run
1. Open the `.ipynb` file using Google Colab.
2. Add your Groq API key in Colab Secrets as `GROQ_API_KEY`.
3. Enable notebook access to the secret.
4. Run the notebook cells in order.
5. Test the chatbot using the sample questions.

# Learning Outcomes
- Understanding LLMs and AI assistants.
- Creating prompts using LangChain.
- Connecting Groq models.
- Maintaining conversation history.
- Performing automated chatbot testing.
- Understanding temperature settings.
- Differentiating plain code, LLM calls, and AI agents.

**Note:** Cafe Napoli is a sample business created for this workshop project. Menu items and prices are illustrative.
