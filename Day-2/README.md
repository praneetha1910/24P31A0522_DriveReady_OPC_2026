# Day 2 – Prompts, Memory and Python Concepts
------------------------------------------------

# Description
In this task, I worked on basic concepts used in developing an AI assistant for a bakery called **Sweet Crumbs**. I practised how messages are structured, how to write system prompts, and how examples can guide an assistant's responses.
I also worked with Python dictionaries, JSON data, functions, decorators, and exception handling through simple examples.

# Concepts Covered

- Message Structure: Created messages using system, user, and assistant roles.
- System Prompts: Defined the assistant's role, bakery details, rules, and response format.
- Few-Shot Prompting: Used sample question-and-answer pairs to demonstrate how the assistant should respond.
- JSON Handling: Converted Python dictionaries into JSON and read JSON data back into Python.
- Memory Using Dictionaries: Stored and retrieved information such as name, favourite cake, and other details.
- Python Dictionaries:Created, accessed, added, and updated student and order information.
- Functions:Created a function to retrieve cake prices.
- Decorators:Practised using a decorator to execute additional statements before and after a function.
- Exception Handling:Used `try-except` blocks to handle errors such as division by zero, invalid input, and unavailable cake names.

# Tools Used
- Python
- Google Colab
- JSON

# Practical Work
All the concepts were practised using small Python code examples. The bakery examples were used to understand message handling, prompts, sample responses, and storing order details.
